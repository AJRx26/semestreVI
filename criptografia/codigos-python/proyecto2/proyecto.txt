- Dada una implementación para crear un chat basado en sockets TCP provista por el profesor, modifica el código para que todas las transmisiones estén cifradas y protegidas con un MAC.
- Utiliza cualquier variante segura de AES vista (CBC o CTR). Se usara CTR
- Utiliza HMAC o CMAC. 
- Utiliza el esquema de cifra luego aplica MAC
- Considera que el servidor y cada cliente deben conocer la llave de cifrado simétrico y la llave MAC, para simplificar, dichas llaves estarán en archivos, al ejecutar los clientes simplemente se pasan la llaves como parámetro.
- Cada cliente tiene su llave MAC y su llave de cifrado propia, éstas se le pasan al servidor de forma no segura al inicio
- El servidor debe de tener un mutex para evitar condiciones de carrera
- Tambien debera de tener una funcion que permita al cliente salir mediante un comando, ademas, de reconocer los usuarios/clientes que se conecten.
